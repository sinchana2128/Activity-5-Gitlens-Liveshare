# Activity-5-Gitlens-Liveshare
Collaborative coding using GitLens and Live Share

## Project Description
This project demonstrates collaborative coding
using GitLens and Live Share in Visual Studio Code.
## Project
A simple C program using the greet() function
to display a personalized greeting.

### What We Built Together
We collaboratively developed a `greet()` function in C using Visual Studio Code. The function accepts a person's name as an argument and displays a personalized welcome message. We used Live Share to work together and complete the coding task.

### What I Learned
I learned how to use GitLens to view commit history and Git blame annotations. It helps identify who made changes to the code and when those changes were made. I also learned how Live Share allows two developers to edit and work on the same project in real time.
